# 斗鱼Plus (DouyuPlus)

基于 Xposed 框架的斗鱼客户端（适配 8.2.1.0）增强模块。

- 💻 **源码仓库**：[DouyuPlus](https://github.com/ysl-ovo/DouyuPlus)

---

## 主要功能
- **画质增强**：自动切换最高画质、使用 **SGSR 1.0 + AMD CAS** 代替原有的画质增强算法；
- **弹幕优化**：解锁弹幕 +1、解除 +1 CD 限制、重复弹幕合并；
- **纯净精简**：去除首页与直播间广告、屏蔽升级弹窗；
- **大屏适配**：优化横屏与平板显示布局。

## 使用方法
1. 在 LSPosed 中启用本模块，作用域勾选「斗鱼」；
2. 强行停止斗鱼客户端后重新打开即可生效；
3. 在斗鱼「我的」页面左上角点击图标即可进入设置面板。
